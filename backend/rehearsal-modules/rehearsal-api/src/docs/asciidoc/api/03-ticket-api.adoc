[[Ticket-API]]
== 5. 변화 카드 및 모바일 다운로드 API

[[Ticket-Submit]]
=== 5.1. 변화 카드 발급 요청

`POST /api/v1/sessions/{sessionId}/ticket`

리허설이 완료된 세션의 변화 카드 발급을 시작합니다. 응답이 `PENDING`이면 아래 조회 API를 폴링합니다.

operation::ticket-submit[snippets='http-request,request-headers,path-parameters,http-response,response-fields']

[[Ticket-Poll]]
=== 5.2. 변화 카드 발급 상태 조회

`GET /api/v1/sessions/{sessionId}/ticket`

`GET` 요청은 Gemini를 다시 호출하지 않고, 이미 생성되어 저장된 티켓 작업 결과만 반환합니다.
`downloadUrl`과 `qrPayload`는 프론트의 `/download/{sessionId}` 모바일 페이지 주소입니다.

operation::ticket-poll-completed[snippets='http-request,request-headers,path-parameters,http-response,response-fields']
