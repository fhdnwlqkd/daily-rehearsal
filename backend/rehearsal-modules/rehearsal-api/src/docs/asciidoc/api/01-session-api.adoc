[[Context-Poll]]
=== 2.4. Context 상태 조회

`GET /api/v1/sessions/{sessionId}/context`

세션의 context 추출 상태와 결과를 조회합니다.

`GET` does not invoke AI again. It reads the latest context state and result stored in RDB.
